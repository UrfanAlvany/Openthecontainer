# Take in playtest feedback

1. Save the feedback verbatim to `playtests/YYYY-MM-DD.md` under a `## Raw` heading,
   with the build (commit hash) it refers to.
2. Hand it to the `playtest-analyst` agent to classify and prioritise.
3. Fix bugs first, then the top 3 feel/pacing items. Log any direction change with the
   `log-decision` skill.
4. Reply to Urfan with: what you changed, what you deliberately didn't (and why), and the
   link to the new build.
